隐私政策

你的文件留在你的 Mac 上。这里说明应用的本地处理，以及网站和反馈服务的区别。

生效日期：2026 年 11 月 4 日

适用范围

本政策适用于 Reclaimora 的 Mac App Store 沙盒版本、直接分发版本，以及本支持网站。更新日期为 2026 年 11 月 4 日。

应用内的数据处理

Reclaimora 在你的 Mac 上分析用户授权的文件、存储占用、应用关联文件和照片。应用不包含广告 SDK、遥测、文件上传或应用内网络请求，不向开发者发送扫描文件、文件名、扫描结果或清理记录。

保存在本机的内容

设置、扫描缓存、清理及恢复记录、忽略列表和目录授权书签保存在 Mac 本机。商店版使用 App Sandbox；直接分发版可能使用不同的数据目录。删除应用程序本身不保证这些数据会一并删除。请通过应用提供的设置管理记录和权限。

权限和商店版边界

文件访问受用户选择的目录及 macOS 权限限制；照片和可选通知权限在使用相关功能时请求。商店版不清理第三方偏好设置、容器、共享应用数据、启动项或浏览器数据。完全磁盘访问不能解除 App Sandbox 限制。当前导航不包含浏览器隐私清理、登录项或扩展管理页面。

文件清理和恢复

普通文件清理移入系统废纸篓，仍占用磁盘空间；应用不提供永久删除或清空废纸篓。恢复需要记录中的文件仍存在、身份一致、原位置可用，且访问权限允许。删除历史记录会移除对应的应用内恢复入口，不会删除废纸篓文件。Photos 图库照片的删除和“最近删除”恢复由 Photos 管理。

你可以如何管理

可在系统设置撤销照片和通知权限，在应用权限界面重新选择目录；可管理忽略项及清理记录。撤销权限可能导致扫描或恢复不可用。若需保留恢复能力，请保留原应用、恢复记录及废纸篓文件。

支持网站和 GitHub

本站由 GitHub Pages 托管，不使用分析脚本、广告、跟踪像素、第三方字体或自建表单。访问网站时，GitHub 可能处理 IP 地址和请求日志等信息；这与 Reclaimora 应用的本地处理不同。GitHub Issues 反馈由你主动提交，内容默认公开，并由 GitHub 按其隐私政策处理。

联系与政策更新

网站和应用的支持维护者为 silvesun。支持与隐私问题可通过 GitHub Issues 提交；请只描述问题，不附私人文件、账号信息、完整路径或未经脱敏的记录。后续政策变化会在本页公布并更新日期。
